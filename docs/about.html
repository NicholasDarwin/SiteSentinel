A second opinion on any website.

SiteSentinel looks at a site the way a careful security reviewer would, then writes down what it saw so you can check its work.

60+
checks across nine categories, from TLS and headers to typosquats and WHOIS age.
9
inspectors that run in parallel, each returning its own score and evidence.
MIT
licensed. Every rule and score weight is in the source, nothing is hidden.

Why it exists

Most website scanners hand back a grade and a list of red labels. That is fine until a result looks wrong, and then there is nothing to check it against.

SiteSentinel keeps the receipts. Each finding carries the evidence it was based on, the points it cost and a plain explanation of the fix. When a result could be a false positive, the report says so instead of guessing.

What it won't do

It only makes the requests a normal visitor's browser would: it fetches public pages, reads response headers, looks up DNS and WHOIS records and asks Google Safe Browsing when a key is configured.

It does not scan ports, try passwords, submit forms or send attack payloads. Addresses on private networks are refused before any request is made.

How it's built

  • ServerNode.js and Express. Each category is its own check module under src/checks.
  • Page analysisAxios for requests, Cheerio for HTML, Puppeteer for pages that need a real browser.
  • ScoringOne file, score-calculator.util.js, holds every weight. Tests cover it with Jest.
  • InterfacePlain HTML, CSS and JavaScript with no build step. The seal is drawn from the address you type.
